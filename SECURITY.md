# Security / Güvenlik

Do not post vulnerabilities with exploit details, tokens or private data in public issues. Use the repository's GitHub **Security → Report a vulnerability** option when enabled. If unavailable, open a minimal issue asking the maintainer for a private reporting channel, without disclosure details. No response-time guarantee is offered. If your token leaked, reset it immediately in Discord Developer Portal; changing Git history alone is insufficient.

Supported source is the current main branch. Run only reviewed changes and keep Node.js/dependencies updated after testing. The URL syntax filter is not a reputation scanner, DNS validator or anti-phishing service. Managers remain responsible for sources. Operators can inspect process memory and configuration; Discord stores public cards. This project does not provide secret storage or private resource sharing.

Açık ayrıntılarını, token veya özel verileri açık issue'ya yazmayın. Etkinse GitHub **Security → Report a vulnerability** kullanın. Yoksa ayrıntı vermeden özel iletişim kanalı talep eden bir issue açın. Yanıt süresi garantisi yoktur. Sızan tokenı Portal'da hemen sıfırlayın; yalnızca Git geçmişinden silmek yetmez. Desteklenen kaynak güncel main dalıdır. Adres filtresi güvenlik/DNS doğrulaması değildir; kaynakları yönetici seçer. Operatör RAM/yapılandırmayı görebilir; Discord açık kartları saklar.
